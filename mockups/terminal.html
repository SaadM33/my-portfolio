About

I started with the ALX Software Engineering program in 2023, building a Python/Flask AirBnB clone and learning that “it works on my machine” is a bug report, not an answer.

Since 2025 I've been at 1337, the 42 school in Morocco: no teachers, no lectures, peer review, and a norm that rejects any function over 25 lines. FT_IRC(8)System Manager's ManualFT_IRC(8)

NAME

ircserv — a non-blocking IRC server written in C++98

SYNOPSIS

./ircserv port password

DESCRIPTION

A single-process, single-threaded server that multiplexes every client socket through one poll() loop — no forks, no threads, no blocking reads. Partial messages are buffered per client until a full \r\n line arrives, so it survives nc sending one byte at a time.

Implements authentication, nicknames, channels and operator privileges, and was tested against irssi as the reference client.

PASS NICK USER
registration handshake
JOIN PART PRIVMSG
channels and direct messages
KICK INVITE TOPIC
operator commands
MODE +i +t +k +o +l
invite-only, topic lock, key, op, user limit

NAME

inception — a small production-style stack, one service per container

SYNOPSIS

make up  # docker compose -f srcs/docker-compose.yml up --build

DESCRIPTION

Three hand-written Dockerfiles on Debian — no pulled images. NGINX is the only entrypoint, on 443 with TLSv1.2/1.3; it proxies to WordPress + php-fpm, which talks to MariaDB over a private bridge network. Database and site files persist in named volumes, and every container restarts on crash.

CUB3D(6)Games ManualCUB3D(6)

NAME

cub3D — a Wolfenstein 3D–style raycasting engine in C

SYNOPSIS

./cub3D maps/level.cub

DESCRIPTION

Parses a .cub map file, validates that it's closed, then casts one ray per screen column with DDA to find wall hits. Walls are textured per face (N/S/E/W) with fisheye correction; floor and ceiling colours come from the map file. Built on MiniLibX — so pixels are written to an image buffer by hand.

Includes a live minimap, sliding wall collisions and mouse look.

MINISHELL(1)User CommandsMINISHELL(1)

NAME

minishell — as beautiful as a shell

SYNOPSIS

./minishell

DESCRIPTION

A bash-like interactive shell, written in C with a partner. Input goes through a tokenizer, a parser that builds a command list, then an executor that wires up fork, pipe and dup2 for each stage.

| < > >>
pipelines and redirections, any length
<< EOF
heredoc, with expansion rules matching bash
$VAR $?
environment and exit-status expansion, ' and " quoting
^C ^D ^\
signals behave like bash, in the prompt and in children
builtins
echo -n, cd, pwd, export, unset, env, exit

BUGS

None known. Zero leaks under valgrind, excluding readline(3) — which is readline's problem.
