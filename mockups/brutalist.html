I like the layer where things can actually go wrong: file descriptors, signals, a server that has to keep 40 clients happy without a single thread.

At 1337 there are no teachers and no slides — just a project spec, peers, and a strict norm. That's how I ended up writing an IRC server around poll(), a shell that survives Ctrl-C mid-heredoc, and a Docker stack where every image is built from a bare Debian base.

Before that, ALX gave me the web side: Python, Flask, MySQL, and a lot of HTML written by hand. These days I'm mixing both — small web services that are boring to run.
